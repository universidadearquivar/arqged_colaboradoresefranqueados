# ◼️ 6. Lista Provisória

## **6.1.POST api/ListaProvisoria/{idListaProvisoria}/Cliente/{idCliente}/AdicionarItens**

O objetivo deste método é permitir que o usuário adicionar/cadastrar até 100 itens na Lista Provisória informada.

### Entrada

Neste serviço o usuário deve informar o id da Lista provisória, o id do cliente e o Json com os campos customizados que deseja adicionar na lista provisória.

* &#x20;idListaProvisoria
* idCliente
* JSON com os campos customizados e valores que serão inseridos na lista provisória.

#### **Request boby**

```json
[
  {
    "valoresCampos": [
      {
        "idCampoCustomizado": "guid",  //id do campo customizado da lista provisoria
        "valor": "string"  //novo valor para o campo customizado 
      }
    ]
  }
]
```

### Validações

O sistema valida:

* &#x20;Permissão do usuário autenticado
* A lista provisória existe e pertence ao cliente informado
* O campo customizado pertence a lista provisoria informada
* Limite de itens excedido
* Status da lista provisória diferente de "**Em Criação**" ou "**Criação com Falha**"

### &#x20;Saída/Retorno

O sistema retorna um Json de response com as informações de todos os itens enviados.

&#x20;Code 201 Created

#### Response

```json
[
  {
    "itemAdicionado": true,  //true ou false
    "descricao": "string",   //sucesso ou motivo da falha para o item
    "valoresCampos": [
      {
        "idCampoCustomizado": "guid", //id do campo customizado da lista provisoria
        "valor": "string"        //valor cadastrado para o campo customizado
      }
    ]
  }
]
```
