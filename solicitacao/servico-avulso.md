# 🟩 Serviço Avulso

O menu Serviço Avulso é utilizado para lançamento de serviços que não são contabilizados pelo sistema de forma automática, mas que devem ser considerados no faturamento.

<figure><img src="../.gitbook/assets/solicita06.png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

{% hint style="success" %}
<mark style="color:green;">Alguns exemplos de serviços que devem ser faturados, mas não são contabilizados de forma automática pelo sistema são:</mark>

* <mark style="color:green;">Suporte técnico</mark>
* <mark style="color:green;">Horas de consultoria</mark>
* <mark style="color:green;">Organização de documentos</mark>
* <mark style="color:green;">Elaboração de projetos, entre outros.</mark>![](<../.gitbook/assets/image (1).png>)
{% endhint %}

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption><p>Cliue na imagem para ampliar.</p></figcaption></figure>

**Unidade:** Informe o nome da Unidade Arquivar responsável pela execução do serviço.

**Adicionar:** Clique para adicionar um novo lançamento.

**Editar:** Clique para editar um lançamento já existente.

**Visualizar:** Clique para visualizar os dados de um lançamento já criado.

**Excluir:** Clique para excluir um lançamento existente.

<figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

**Coluna Pedido:** Exibe o número criado para o lançamento realizado.

**Coluna Cliente:** Exibe o nome do Cliente para qual o serviço foi executado.

**Coluna Solicitante:** Exibe o nome do responsável pelo serviço no cliente.

**Coluna Atendente:** Exibe o nome do Atendente responsável pelo serviço na Unidade Arquivar.

**Coluna Data do Cadastro:** Exibe a data que o lançamento foi realizado no sistema.

**Coluna Data da Execução:** Exibe a data de execução do serviço pela Unidade Arquivar.

## Criando um lançamento de Serviço Avulso

Ao clicar na opção de Adicionar é aberta a tela de lançamento.

<figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

Preencha os campos apresentados na tela:

<figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

Unidade: É exibido já preenchido, pois considera a informação da tela anterior.
