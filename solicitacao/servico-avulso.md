# 🟩 Serviço Avulso

O menu Serviço Avulso é utilizado para lançamento de serviços que não podem ser contabilizados pelo sistema de forma automática, mas que devem ser considerados no faturamento.

{% hint style="success" %}
<mark style="color:green;">Alguns exemplos de serviços que devem ser faturados, mas não são contabilizados de forma automática pelo sistema são:</mark>

* <mark style="color:green;">Suporte técnico</mark>
* <mark style="color:green;">Horas de consultoria</mark>
* <mark style="color:green;">Organização de documentos</mark>
* <mark style="color:green;">Elaboração de projetos, entre outros.</mark>
{% endhint %}
