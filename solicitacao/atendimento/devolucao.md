# 🔹 Devolução

## Atendimento de uma Solicitação de Devolução - Documento, Caixa ou Subcaixa

Nesta tela são exibidas as solicitações de devolução feitas pelos clientes por meio do menu Solicitações > Devolução, aqui são consideradas todas as solicitações de devolução, seja ela de documento, caixa ou subcaixa.

<figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

No cabeçalho são apresentadas as opções de filtros disponíveis:

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

**Caixa ou Subcaixa:** Permite a busca do pedido de devolução pelo número da caixa ou da subcaixa.

**Código Documento:** Permite a busca do pedido de devolução pelo código do registro.

**Código Devolução:** Permite a busca do pedido de devolução pelo código de consulta anotado ou colado no verso do documento no atendimento do pedido de consulta.

**Tipo de Guarda:** Exibe uma modal para seleção dos pedidos realizados para Guarda Terceirizada e para Guarda Interna, na visão do cliente (apenas quando o cliente possui as duas modalidades contratadas).

**Empresa:** Exibe a lista de clientes de guarda terceirizada atendidos pela Unidade.

**Pesquisar:** Clique para efetivar a busca com os filtros selecionados.
