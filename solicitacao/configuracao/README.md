# 🟩 Configuração

Neste Menu é realizada a configuração do Fluxo de Solicitações e Devoluções do cliente, ou seja, aqui é definido o (s) processo (s) que será realizado no sistema para atendimento das demandas do cliente.

{% hint style="danger" %}
<mark style="color:red;">O cadastro do fluxo ocorre no momento de Criação da Base do ArqGED que é realizado pela Arquivar Master. O cadastro do fluxo é realizado quando o cliente possui Guarda Interna (CEDOC) e/ou Guarda Terceirizada. A Unidade Arquivar deve passar esta informação na solicitação de nova base.</mark>
{% endhint %}
