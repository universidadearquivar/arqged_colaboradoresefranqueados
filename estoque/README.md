# 🗄️ Estoque

O menu Estoque é utilizado pelas unidades que oferecem serviços de guarda e precisam controlar o estoque físico de caixas e pastas. Neste menu o gerenciamento do estoque é feito e a unidade consegue saber quando precisa adquirir mais caixas e como as caixas estão sendo utilizadas, por exemplo. O menu Estoque é composto pelo submenu [Caixa](caixa/).
