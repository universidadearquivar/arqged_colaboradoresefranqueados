# 🔹 Aba Histórico Serviços

{% embed url="https://app.supademo.com/demo/cmbgvmr6a55yssn1rvg93ob4x" %}

Esta aba apresenta todas as alterações ou acréscimos de serviços feitos no contrato do cliente.

**Ícone Visualizar:** Utilizado para visualizar mais detalhes do registro selecionado.

**Coluna Serviço:** Mostra o serviço que foi cadastrado ou editado.

**Coluna Nome para Espelho:** Exibe o nome informado no campo Nome para Espelho que será exibido no relatório de faturamento.

**Coluna Data Cadastro:** Exibe a data em que o serviço foi incluído no contrato.

**Coluna Usuário Cadastro:** Exibe o nome do usuário que fez a inclusão ou edição do serviço no contrato.

**Coluna Data Última Alteração:** Exibe a data e hora da última edição feita no cadastro do serviço.

**Coluna Usuário Última Alteração:** Exibe o usuário que realizou a última edição feita no cadastro do serviço.

**Coluna Última Alteração:** Informa se a última alteração feita no cadastro do serviço foi de inclusão, edição ou exclusão.

<figure><img src="../../../.gitbook/assets/contratos09 (1).png" alt=""><figcaption><p>Clique na imagem para ampliar.</p></figcaption></figure>

Ao selecionar um registro e clicar no ícone “Visualizar”, é aberta a tela “Histórico Serviço”, que exibe informações detalhadas sobre as alterações feitas ao cadastro do serviço no contrato.

Clicando no ícone “Gerar Excel” é possível gerar um relatório de todas as alterações realizadas.
